A little help getting connected.

    
1
Open LANFLUX on both devices
For local sharing, connect to the same Wi-Fi. On your phone, use your computer's local IP address and port, such as http://192.168.1.10:8000. Localhost only opens this device.

    
2
Pair with a private room
Create a room and share its link, code, or QR. The second browser joins with a device name. Anyone with the link can join an empty slot, so share it privately.

    
3
Choose, approve, and download
Select files on either device. The receiver approves each file before it starts. Download received files before closing the tab or clearing history. Downloads are never saved on the server.

    
Connection & browser support
Use a recent Chrome, Edge, Firefox, or Safari. HTTPS is recommended, especially on mobile. Both tabs must stay open; mobile browsers may pause transfers in the background. Some Wi-Fi networks block devices from reaching each other.
WebRTC encrypts your transfer. A direct route connects the browsers; a TURN relay route carries encrypted traffic through a relay server. The connection panel shows the detected route.

    
Integrity & measurements
LANFLUX computes a SHA-256 digest before sending, then verifies the received bytes before making a download available. A mismatch fails the transfer. This checks byte integrity; a peer-supplied digest does not authenticate who sent the file.
Network diagnostics measure payload throughput and WebRTC state. Export finished records as CSV or a readable report. Your entered test conditions are recorded separately from browser measurements.

    
This version receives files in browser memory and uses a limited, sequential queue.

    
Rooms expire automatically. Leave and create a new room if pairing fails. Relay connections require an administrator-configured TURN server.
